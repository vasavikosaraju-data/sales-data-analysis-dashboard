# Sales Data Analysis Dashboard

## Overview
This project analyzes retail sales data to uncover business insights such as regional performance, product trends, and monthly sales patterns.

## Tools Used
- Python
- Pandas
- Matplotlib

## Key Insights
- Identified top-performing regions based on sales
- Analyzed monthly sales trends
- Found top-selling products
- Compared profit across regions

## Project Steps
1. Data cleaning and preprocessing
2. Exploratory data analysis
3. Data visualization
4. Insight generation

## Business Value
This project demonstrates how data analysis can help businesses make data-driven decisions and improve performance.

## How to Run
1. Download the dataset
2. Run the Python file (`analysis.py`)
3. View output and charts
